# Video work in this repo

For any video, motion graphic, promo, reel or explainer request, load the `story-motion` skill (`.claude/skills/story-motion/SKILL.md`) together with `/hyperframes`. It sets the required caliber: a character-driven story, match cuts, a voiceover, SFX on every action, and a music bed. The reference implementation is `motion-reel-src/`.
