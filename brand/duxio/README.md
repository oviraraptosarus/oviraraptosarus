# DUXIO brand kit

Everything about DUXIO in one place, so no session has to ask for it again. The rules live in the skills (`.claude/skills/duxio-brand`, `duxio-vsl`, `duxio-website`); this folder holds the files and the facts they point to.

## Quick facts
- **What:** DUXIO builds and runs the follow up that moves serious buyers from first interest to a booked sales call, for coaches and consultants selling high ticket offers.
- **Hero:** "Turn interested leads into paying clients."
- **CTA:** "Book a Strategy Call" (short: "Book a Call"). Never a free audit.
- **Mechanism (always four):**
  1. Every lead gets an answer.
  2. Serious buyers get sorted.
  3. 21 day follow up and call reminders.
  4. Quiet leads reopened.
- **Price (website only):** $397 one time setup, then $300 to $800 a month.
- **Proof:** no public client results yet. HBR 2011 lead-response stat (cite it).
- **Site:** https://duxio-website-for-coaches.vercel.app/ (repo `oviraraptosarus/duxio-website-for-coaches`).
